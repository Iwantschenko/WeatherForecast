# 🌦 Weather Forecast App
[DEMO] -> https://spontaneous-lollipop-8c808c.netlify.app/
Цей проєкт — SPA застосунок для перегляду прогнозу погоди. Реалізовано дві основні сторінки: прогноз на декілька днів та детальний прогноз на вибраний день. Також є підтримка перемикання теми (light / dark).

## 🔎 Основний функціонал

- Перегляд прогнозу на декілька днів
- Детальна інформація по вибраному дню
- Перемикач теми (світла/темна)
- Інтеграція з OpenWeather API
- Лінтинг, форматування та автоперевірка перед комітами

## ⚙️ Стек технологій

- React + TypeScript
- React Router
- SCSS
- Vite
- ESLint + Prettier
- Husky + lint-staged
- OpenWeather API
